# Visual style update

The frontend has been restyled to combine a clean, editorial dark interface inspired by Supabase's landing-page feel with MR RICH CONNECT's own futuristic community identity.

- Near-black navy foundation and layered blue panels
- Blue/cyan accents instead of green
- Clean, high-contrast typography and more restrained borders
- Subtle futuristic radial lighting rather than excessive neon
- Responsive mobile navigation and cards retained

This is a visual update. It does not add backend functionality by itself. Keep all Supabase credentials in Render environment variables and never commit secrets.
